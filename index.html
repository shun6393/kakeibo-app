CLOUD SAVE

クラウド保存を確認

端末データをクラウドへ保存します。先にJSONバックアップを取得することをおすすめします。

クラウド側のデータの方が新しい可能性があります

それでも古い端末データで上書きする場合は、半角大文字で OVERWRITE と入力してください。

CLOUD LOAD

端末データの置換を確認

現在の端末データを安全退避し、JSONダウンロードを開始してから、クラウドデータで全置換します。

DELETE ALL

すべてのデータを削除しますか？

次のデータがすべて削除され、元に戻せません。先にJSONバックアップを取得することを強くおすすめします。

  • 初期残高と基準日
  • すべての収入・支出
  • サブスクリプション
  • 追加カテゴリ・小カテゴリ
  • 追加した支払い・受取方法
  • アプリ設定と復元前の一時退避
